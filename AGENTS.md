# Точка опоры: быстрые точечные правки

- Пользователь работает с https://pauline-p-s.github.io/tochka-opory/. Публикация: remote `github`, branch `main`, workflow `Publish website`. Не публиковать в старый Sites.
- Сначала читать только файл нужного раздела и связанные CSS-селекторы через `rg -n`. Не выводить целиком все файлы страницы.
- `app/page.tsx`: шапка и первый экран; `app/content.tsx`: порядок разделов.
- `app/sections/<name>.tsx`: needs, about, approach (УТП), recovery-route, directions, team, space, result, reviews, prices, faq, contacts, footer.
- `app/site-content.ts`: списки карточек, шагов, специальностей, вопросов и документов. Искать нужную именованную константу, а не читать весь файл.
- `app/sections/shared.tsx`: общие Heading и Photo. `app/brand.tsx`: SVG логотипы.
- `app/team-content.ts`: профили; `published: false` скрывает Дмитрия Зуева. Фото и дипломы ожидаются.
- `app/price-content.ts`: категории и цены; `app/prices/<slug>/page.tsx`: отдельные страницы, `sections/price-detail.tsx`: общий шаблон. Не выдумывать отсутствующие цены.
- `app/services.css`: стили профилей, цен и карты.
- `app/contact-dialog.tsx`: модальная форма и кнопки её открытия.
- `app/desktop-motion.tsx` и `app/motion.css`: анимации десктопа; содержимое всегда доступно без JavaScript, на мобильном и с reduced motion.
- `app/globals.css`: базовые стили; `app/refinements.css`: действующие уточнения. Менять существующий селектор, не дописывать цепочки переопределений.
- Montserrat, #3E4446 / #0E725A / #F1F1F1, прямые углы. Сохранять согласованные тексты и заглушки.
- Не изменять и не коммитить пользовательские копии `app/* 2.*`.
- Для небольшой CSS/текстовой правки: проверить diff, дождаться успешной сборки и публикации GitHub Actions, затем проверить изменённый участок. Не запускать полный набор проверок повторно без новой причины.
- Для поведения/рефакторинга: typecheck, сборка и целевая проверка в браузере. Не читать длинные логи успешной сборки повторно.
- Не создавать новые задачи/подагентов без запроса пользователя. Не устанавливать зависимости для рутинной правки.

- Правки заказчика от 17.09.2026: направления и результат сняты с главной; 4 шага; нет лицензии/физиотерапии/индивидуальной программы в публичных блоках. Новый знак/композиция из логотипа отменены пользователем.
